# Power BI Dashboard Guide — ds-101 (Pertemuan 10–15)

Star-schema datasets for each notebook are prepped in `powerbi/<pertemuan-XX>/` as CSVs
with surrogate keys already joined. This guide is the manual build plan for Power BI
Desktop — the data prep is done; what's left is importing, modeling, and visuals.

## General workflow (applies to every pertemuan)

1. **Get Data** → Text/CSV → import all files in the pertemuan's folder.
2. **Power Query** (Transform Data): check column types — `*_key` columns as Whole
   Number, dates as Date, currency/measures as Decimal/Whole Number — then
   **Close & Apply**.
3. **Model view**: drag `dim.*_key` → `fact.*_key` to create 1-to-many relationships
   (dimension → fact, single direction). Arrange the fact table centered with
   dimensions around it — that's the star.
4. If a `dim_date` table exists, mark it as a **Date Table** (Table tools → Mark as
   date table → pick the date column) to enable time-intelligence DAX.
5. Add the **DAX measures** listed below (right-click the fact table → New Measure).
6. Build the **report page** with the suggested visuals.
7. **Format**: title, consistent color theme, tooltips, slicers for key dimensions.

## Pertemuan 10 — Beras Supply Chain Risk

**Files:** `dim_bulan.csv`, `fact_beras.csv`, `risk_register.csv`

**Relationships:** `dim_bulan.bulan_key` → `fact_beras.bulan_key`.
`risk_register` stands alone (reference table, no FK — used in a matrix visual).

**DAX measures** (on `fact_beras`):
```
Harga Rata-rata = AVERAGE(fact_beras[harga_beras])
Total Stok = SUM(fact_beras[stok_beras])
Total Produksi = SUM(fact_beras[produksi_padi])
Curah Hujan Rata-rata = AVERAGE(fact_beras[curah_hujan])
```

**Visuals:**
1. Line chart — `dim_bulan.nama_bulan` (sorted by `urutan`) vs `harga_beras` & `stok_beras` (dual axis).
2. Combo chart — `produksi_padi` (bars) vs `curah_hujan` (line) by month.
3. Table/matrix from `risk_register` — `deskripsi`, `likelihood`, `impact`,
   `skor_risiko`, `mitigation`; conditional formatting on `skor_risiko`
   (red = 9, yellow = 6).
4. Cards — `Harga Rata-rata`, `Total Stok`.

> Tip: Right-click `dim_bulan.nama_bulan` → *Sort by column* → `urutan`, so months
> display Jan→Jun instead of alphabetically.

## Pertemuan 11 — Sustainable Logistics

**Files:** `dim_moda.csv`, `fact_moda.csv`

**Relationships:** `dim_moda.moda_key` → `fact_moda.moda_key`.

**DAX measures:**
```
Total Emisi = SUM(fact_moda[emisi_co2_kg])
Total Biaya = SUM(fact_moda[biaya_rp])
Skor Keberlanjutan Avg = AVERAGE(fact_moda[skor_keberlanjutan])
```

**Visuals:**
1. Bar chart — `nama_moda` vs `emisi_co2_kg`, `biaya_rp`, `lead_time_jam`.
2. Scatter chart — X = `biaya_rp`, Y = `emisi_co2_kg`, size = `kapasitas_ton`,
   legend = `nama_moda` (cost-vs-emission tradeoff).
3. Gauge/bar — `skor_keberlanjutan` per mode (highlights the most sustainable option).

## Pertemuan 12 — Reverse Logistics (Inspection)

**Files:** `dim_kondisi.csv`, `fact_inspeksi.csv`

**Relationships:** `dim_kondisi.kondisi_key` → `fact_inspeksi.kondisi_key`.

**DAX measures:**
```
Jumlah Produk = COUNTROWS(fact_inspeksi)
Jumlah Layak Ekspor = CALCULATE([Jumlah Produk], dim_kondisi[kondisi] = "Layak Ekspor Ulang")
% Layak Ekspor = DIVIDE([Jumlah Layak Ekspor], [Jumlah Produk])
```

**Visuals:**
1. Donut/pie — `kondisi` vs `Jumlah Produk` (proportion per condition).
2. Table — `id_produk`, `kondisi`, `aksi_rekomendasi` (full inspection log).
3. Card — `% Layak Ekspor`.

## Pertemuan 14 — Route Optimization

**Files:** `dim_pelabuhan.csv`, `fact_rute.csv`, `fact_optimasi.csv`

**Relationships:** `dim_pelabuhan.pelabuhan_key` → `fact_rute.pelabuhan_key`
**and** → `fact_optimasi.pelabuhan_key` (two fact tables sharing one dimension —
a multi-fact star / "galaxy" schema).

**DAX measures:**
```
Total Jarak = SUM(fact_rute[jarak_km])
Biaya per Ton Avg = AVERAGE(fact_rute[biaya_rp_ton])
Total Ton Terkirim = SUM(fact_optimasi[jumlah_ton_terkirim])
Total Biaya Optimal = SUM(fact_optimasi[biaya_rp])
```

**Visuals:**
1. Bar chart — `nama_pelabuhan` vs `jarak_km`, `waktu_jam`, `biaya_rp_ton`.
2. Stacked bar — `nama_pelabuhan` vs `jumlah_ton_terkirim` (from `fact_optimasi`,
   shows how the OR-Tools solver allocated the 5,000-ton requirement).
3. Card — `Total Biaya Optimal` (≈ Rp 67.8B).
4. Optional: map visual if port lat/long coordinates are added later.

> Note: `fact_optimasi` was generated by re-running the notebook's OR-Tools LP solver
> directly (not hand-entered), so the shipment allocation and cost reflect the actual
> optimal solution.

## Pertemuan 15 — Suez Canal Disruption

**Files:** `dim_date.csv`, `dim_status.csv`, `fact_suez.csv`

**Relationships:** `dim_date.date_key` → `fact_suez.date_key`;
`dim_status.status_key` → `fact_suez.status_key`.
Mark `dim_date` as a **Date Table** (column `tanggal`).

**DAX measures:**
```
Total Nilai Tertahan = SUM(fact_suez[estimasi_nilai_tertahan_usd_miliar])
Antrean Puncak = MAX(fact_suez[kapal_mengantre])
Kenaikan Minyak Avg = AVERAGE(fact_suez[kenaikan_harga_minyak_persen])
```

**Visuals:**
1. Line chart — `tanggal` vs `kapal_mengantre` & `estimasi_nilai_tertahan_usd_miliar`
   (dual axis) — the escalation curve.
2. Combo chart — `tanggal` vs `kenaikan_harga_minyak_persen` (spike-then-drop pattern).
3. Timeline/table — `tanggal`, `status`, `kategori`, colored by `kategori`
   (Insiden = red, Penanganan = orange, Resolusi = green).
4. Cards — `Antrean Puncak`, `Total Nilai Tertahan`.

## Pertemuan 13 — Global Coffee Supply Chain (pilot, reference)

**Files:** `dim_date.csv`, `dim_negara.csv`, `fact_supply_chain.csv`

**Relationships:** `dim_date.date_key` → `fact_supply_chain.date_key`;
`dim_negara.negara_key` → `fact_supply_chain.negara_key`. Mark `dim_date` as a
Date Table (column `tanggal`).

**DAX measures:**
```
Total Ekspor = SUM(fact_supply_chain[ekspor_ton])
Rata-rata Harga = AVERAGE(fact_supply_chain[harga_usd_per_kg])
Total Stok = SUM(fact_supply_chain[stok_ton])
```

**Visuals:**
1. Line chart — `tanggal` vs `Total Ekspor` / `Rata-rata Harga`, legend = `nama_negara`.
2. Map/bar — `benua` vs `Total Stok`.
3. Slicers — `nama_negara`, `tahun`/`bulan`.
4. Cards — `Total Ekspor`, `Rata-rata Harga`.
